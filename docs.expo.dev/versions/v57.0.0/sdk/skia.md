Android, iOS, tvOS, Web, Included in Expo Go

`@shopify/react-native-skia` brings the Skia Graphics Library to React Native. Skia serves as the graphics engine for Google Chrome and Chrome OS, Android, Flutter, Mozilla Firefox and Firefox OS, and many other products.

## Installation

```sh
# npm
npx expo install @shopify/react-native-skia

# yarn
yarn expo install @shopify/react-native-skia

# pnpm
pnpm expo install @shopify/react-native-skia

# bun
bun expo install @shopify/react-native-skia
```

If you are installing this in an [existing React Native app](https://docs.expo.dev/bare/overview.md), make sure to [install `expo`](https://docs.expo.dev/bare/installing-expo-modules.md) in your project. Then, follow the [installation instructions](https://shopify.github.io/react-native-skia/docs/getting-started/installation/) provided in the library's README or documentation.

### Web

If you want to use Skia on web, you will need to follow [web installation instructions](https://shopify.github.io/react-native-skia/docs/getting-started/web/#expo) to load CanvasKit.
