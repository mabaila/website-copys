Android, iOS, Web, Included in Expo Go

`react-native-gesture-handler` is a library for handling complex gestures. From its README:

> This library provides an API that exposes mobile platform-specific native capabilities of touch and gesture handling and recognition. It allows for defining complex gesture handling and recognition logic that runs 100% in the native thread and is therefore deterministic.

## Installation

```sh
# npm
npx expo install react-native-gesture-handler

# yarn
yarn expo install react-native-gesture-handler

# pnpm
pnpm expo install react-native-gesture-handler

# bun
bun expo install react-native-gesture-handler
```

If you are installing this in an [existing React Native app](https://docs.expo.dev/bare/overview.md), make sure to [install `expo`](https://docs.expo.dev/bare/installing-expo-modules.md) in your project. Then, follow the [installation instructions](https://docs.swmansion.com/react-native-gesture-handler/docs/fundamentals/installation) provided in the library's README or documentation.
